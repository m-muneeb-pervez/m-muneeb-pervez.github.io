ICLR 2027

safeMAS

A multi-layer security framework for evaluating the robustness and safety of multi-agent LLM systems

Key findingAttack success depends on which agent is compromised.

  • Evaluates robustness and safety under adversarial manipulation across multiple architectures
  • A second failure mode: agent-in-the-middle attacks on the channels between agents

Research

LLM and multi-agent security

  • How architecture shapes risk: which agents an attacker needs to compromise, and which channels they can reach [3]
  • Internal threats: an agent given a legitimate task and no external attacker reasons its way into harmful, unsanctioned actions
  • Open question: do multi-agent architectures and tool partitioning change how often this happens and how much damage it causes?

Systems security

  • Memory-safety exploitation and binary analysis, from coursework projects
  • Web application attacks and their defenses
  • Groundwork for automated vulnerability detection and program analysis

Also: usable security and privacy

  • Consent and privacy literacy in predatory apps [1]
